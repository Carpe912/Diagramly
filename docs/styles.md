# 图形与线条样式

选中节点或连线后，右侧「属性」页显示样式。画布支持 Shift 多选；图层列表支持 Shift、⌘/Ctrl 切换多选。批量设置作为一条命令提交，可整体撤销。不同属性值显示为空或「多种值」，修改某个属性不会覆盖其余属性。

节点支持八种预设配色、边框显示、颜色、宽度、实线／虚线／三种点线、锐利／圆角、不透明度。活动的内部部件仍属于同一个业务节点，不能单独编辑；泳池与泳道保留各自的背景、标题和角色工具栏。

连线另支持：

- 普通连线、双线链接、块箭头和简单箭头。
- 直线、正交折线、水平肘形、垂直肘形和实体关系路径；普通连线支持曲线。
- 两端无标记、经典／三角／开放箭头及细版、圆形、菱形及细版，独立设置填充、大小与端点间距。
- 无跨线、圆弧、间断、尖角及跨线尺寸。实际交点由当前路径计算，端点相接、平行重叠不产生跨线；同一交点只由一条线跨越。

选项按形态生效：块箭头支持有无三角端点，双线链接没有端点标记，简单箭头固定为直线与末端箭头。曲线和轮廓箭头不使用跨线。相关控件自动禁用；切换形态不会丢弃原先保存的普通连线配置。

所有样式保存在结构化 `node.appearance`／`edge.appearance` 中，字段可选，旧文档沿用原外观。`node.appearance.accent` 是节点边框颜色；`edge.appearance.strokeColor` 是连线颜色。不透明度 0% 完全透明、100% 完全不透明。

界面和 Agent 共用 `node.appearance`、`edge.appearance` 命令；`edge.update` 的外观补丁也按字段合并。Schema 校验颜色、枚举与数值范围，非法设置使整笔命令回滚。

JSON、XML、本机缓存和远程流程保存均保留样式；XML 同时写入标准 mxGraph 样式字段。固定端口的间距通过沿端口外法线偏移实现，保持连接的端口身份。PNG 与 Coopwire 预览使用同一个渲染适配器，包含线型、箭头、透明度和跨线效果。单纯修改样式只保存流程关系及 XML／PNG，不修改业务活动详情；远程撤销会保存还原后的外观。
