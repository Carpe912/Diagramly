# 自有业务详情

活动节点通过 entityId 关联文档内业务实体。选中活动后在右侧展示原生 Vue 业务详情，无须宿主、iframe、postMessage 或旧 Coopwire 活动 ID。泳池、泳道等图形只展示其适用属性。

## 表单与关联

详情按基本信息、应用设备、时间周期、输入输出、关联业务组织。人工线上、人工线下、系统操作、接口、子流程与引用活动使用各自字段。较窄面板自动改为单列，复杂列表用统一模态表单编辑。

基本信息包括名称、类型、描述、关键活动、进度和补充说明。输入输出包含对象、数据表与字段、单证及附件，异常和痛点可以独立增删改。需求与待办通过稳定 ID 关联。

工作空间管理负责维护角色、应用、设备、操作方式、终端、接口、数据对象、数据表、单证、需求与待办。数据表字段有独立 ID，数据对象可关联多个表；表单选择器从这些自有目录读取。附件通过自有服务上传和下载，不再读取旧业务接口。

引用活动由本应用选择器选择其他文档及其活动；保留源文档和活动 ID。引用不是跨文档实时协同编辑，修改源文档后需要重新读取其最新内容。

## 保存

拖拽创建图形和编辑表单首先执行文档命令，不发送 createAct。图形与表单同属一份 JSON，支持撤销重做。打开独立服务文档后串行自动保存 JSON，并保留 IndexedDB 草稿；本机文档只存 IndexedDB。XML 是可选导入导出格式，不是内部主存储。

远程冲突停止自动保存，用户重新打开时选择服务器版本或将本机草稿另存为新文档。业务目录是工作空间共享数据，修改后立即保存至独立后端，使用单独的记录版本校验；文档关联保存稳定 ID。

旧 Coopwire 适配器、Cookie 代理和锁功能已退出运行代码，不兼容旧图形或旧业务数据。Agent 相关能力不在本轮实现范围。
