# 业务图形详情

选中业务活动、条件判断或子流程后，在右侧属性面板点击「查看业务详情」。详情按旧项目 `UserPortrait/index.vue` 的业务分组组织；泳池和泳道继续使用各自的图形属性和工具栏。

## 已实现

- 活动名称、详细描述、图上显示描述、关键活动、进度。
- 人工线上、人工线下、系统操作、接口对接、引用活动五种活动类型。判断和子流程保留各自类型。
- 补充说明、无／新增／优化／删除差异标记。
- 应用、终端、设备工具和人工线下操作方式；子流程可关联其他流程。
- 单次用时、开始与结束小时、清除时间范围。
- 固定／非固定周期、每日／每周／每月、星期与日期选择、非固定周期说明。
- 显示设置、输入与输出；读取已有调研人员数量及异常、痛点、功能、待办、调研记录等关联业务。
- 详情编辑共用结构化命令、校验、保存、撤销重做；旧文档不要求补齐新字段。

远程模式下点击「加载业务选项」读取当前项目中的应用、设备、流程、终端和操作方式。只更新发生变化的字段，保留未编辑的业务关系和未知显示设置。

## 数据与接口

新增属性保存在业务实体的可选 `details` 对象中，图形几何仍由节点管理。`node.update` 可部分更新详情，显示设置按字段合并，Agent 入口使用同一校验结构。

```json
{
  "type": "node.update",
  "id": "receive",
  "patch": {
    "details": {
      "keyStep": "先确认库存，再提交订单",
      "hoursOnceAct": "2.5",
      "fixedCycleKey": "week",
      "fixedCycleWeekValues": ["1", "3", "5"]
    }
  }
}
```

普通属性使用 `updateAct` 增量更新；清空应用、设备或关联流程时传递旧接口要求的清空标志。补充说明使用 `updateActDetailDesc`，时间范围使用 `addTimeRange`／`updateTimeRange`／`delTimeRange`，每步重新读取活动版本，再保存流程图 XML 和 PNG。

目前补充说明以纯文本编辑，未编辑的已有富文本保持原值；富文本附件上传及关联业务的新建、删除界面尚未迁移。关联业务和调研人员当前只读，沿用后端的独立业务管理，不会在图形保存时覆盖这些关系。
