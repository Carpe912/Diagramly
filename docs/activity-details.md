# 自有业务详情

远程节点有已确认的 `externalRef.id` 和可读取的活动详情时，右侧显示业务详情。本机示例、泳池泳道及没有业务 ID 的图形不显示该标签。每次切换节点均按独立 ID 读取对应详情，不依赖宿主弹窗、iframe 或原前端的嵌入入口。

## 面板布局

详情使用原生 Vue 组件，按基本信息、应用设备、时间周期、输入输出、关联业务五组切换。复杂记录用独立模态框编辑，统一字段间距、双列短字段和底部操作区；较窄窗口时自动单列。

基本信息包含名称、活动类型、描述、关键活动、进度、补充说明和差异标记。应用设备字段按人工线上、人工线下、系统操作、接口、子流程及引用活动区分。时间周期支持单次用时、小时范围、每日、每周、每月及非固定周期。接口活动支持提供和接收数据的应用、接口提供方、接口设计。

输入输出以独立记录展示，弹窗编辑名称、描述、设备与对象操作类型，支持删除。编辑时保留原记录 ID、附件、表字段和单证元数据；支持选择数据对象、数据表及字段、已有表单单证和附件文档。异常和痛点支持新增、编辑、删除，沿用原异常记录的版本校验。其他关联业务当前展示原后端记录，尚未完成各业务模块的全部独立编辑器。

引用活动创建由自有选择器依次选择流程、活动和是否显示角色，确认后创建 `linkAct`；修改既有引用目标使用同一选择器。

## 保存与边界

基本字段通过文档命令提交，保留远程撤销链路。输入输出、异常等独立业务记录保存后重读活动并同步 XML、关系和 PNG，清空之前的撤销历史，避免旧快照覆盖新业务记录。业务记录和流程保存没有后端跨接口事务，保存出错时需读取远端核对，不应盲目重复新增。

仅迁移 `flowchart=1` 场景，不迁移草图模式与锁功能。浏览器沿用同域 Cookie，本机开发通过 `/rest` 代理；不再需要业务详情前端地址或单独部署原前端嵌入页。会话凭证不进入源码、文档、URL或浏览器存储。真实业务写入验证需用户明确授权，自动化测试使用模拟后端。

## IndexedDB 草稿阶段

当前编辑和业务表单保存只写入 IndexedDB 的 `diagramly/drafts`，不挂接后端写入适配器，也不显示统一提交按钮。JSON 文档内的 resources 保存输入输出、异常和痛点记录；远程流程按连接配置分别保存本机草稿，重新打开优先恢复该草稿。后端目前只用于读取流程和业务选项，不会因拖入活动、编辑或删除图形而创建或修改远程业务。
