# 节点对齐

多选节点后，右侧「属性」页提供左、水平居中、右、顶、垂直居中、底对齐。按所选节点的整体包围框对齐。单选或多选节点均可「对齐到网格」，即使隐藏网格也能使用文档中的网格间距。

画布按住 Shift 多选；图层列表可按 Shift 或 ⌘/Ctrl 切换选中状态。节点与连线混选时，对齐只移动节点，相连的线段随节点位置重新路由。

`nodes.align` 命令接受 `ids` 数组和 `mode`（`left`、`center`、`right`、`top`、`middle`、`bottom`、`grid`）。界面与 Agent 使用相同的命令和校验。

- 按绝对画布坐标计算，保存时转换回所属容器的相对坐标，支持跨泳道节点。
- 同时选中父节点和子节点时只移动父节点，保留内部布局，避免重复位移。
- 泳道由泳池统一排布，不能独立对齐。可以选择泳池整体对齐。
- 吸附网格时在泳道有效内容区内选择最近可用网格点；没有可用位置则拒绝。
- 六方向对齐不能将节点移出泳道；无效命令整体回滚，不留下部分移动。
- 对齐不修改业务身份、角色与连接关系，可作为一个步骤撤销、重做；远程模式通过原有的流程关系、XML 和 PNG 保存链路持久化位置。
