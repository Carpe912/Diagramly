# 文档、画布与侧栏

## 文档数据

顶部只保留「文档数据」入口。弹窗中有一个导入按钮，以及导出格式选择和导出按钮：

- 导入 JSON、XML 或 `.drawio`；按内容识别格式。JSON 上限 5MB，XML 与解压后的内容上限 8MB。
- 导出 JSON、XML 或 PNG 图片。JSON/XML 保留完整业务文档、泳池层级、角色、图形外观和画布设置。
- XML 支持 Diagramly 文档、已有 Coopwire 兼容模型、基础矩形／椭圆／菱形，以及单画布 draw.io 文件，包括压缩画布。多画布文件须分别导出，未知模板会明确拒绝，避免静默丢失图形。
- 图片只包含图形、连线、网格和画布背景，不包含选框、工具栏和侧栏。默认透明；最长边限制为 4096 像素，总像素不超过 1200 万。
- 错误文件不会替换当前画布。远程连接期间可导出，须先断开再导入，避免把导入文件意外写入现有远程业务。
- `⌘/Ctrl+S` 打开文档数据弹窗。

## 画布设置

画布右上角「画布设置」可打开网格、设置 5–100px 间距、修改网格线颜色和 0–100% 透明度、选择背景颜色或恢复透明。默认关闭网格，背景透明。网格线透明度 0% 为不透明、100% 为完全透明，网格线透明不影响吸附。网格与图形一起缩放、平移，开启时也按同一间距吸附。

设置通过 `document.canvas.update` 命令保存到文档，可撤销、重做。`gridColor` 为十六进制颜色，`gridOpacity` 为 0–1 的不透明度，界面透明度按相反方向显示。旧文档未包含设置时使用默认值。JSON、XML、PNG 及 Coopwire 流程预览图共用当前设置，PNG 实际像素已验证透明与背景颜色。

## 缩放与平移

- 在画布上滚动滚轮，以鼠标下的内容为中心缩放；按钮和滚轮的交互范围为 10%–400%。
- 选择工具下拖动空白处可平移；按住空格拖拽或使用鼠标中键，可从图形上开始平移。平移工具（H）也可拖动画布任意位置。
- Shift＋滚轮或触控板水平滚动可左右平移。按住 Shift 或 Alt 在空白处拖拽仍可框选。
- 平移不限制到原始画布边缘，放大后可找回左右、上下视野外的图形；纯水平和纯垂直拖拽不会回弹。
- 「适应画布」按全部内容自动缩放。缩放和平移仅影响视口，不改变节点坐标、历史版本或导出图片范围。
- 网格和平移同步移动；侧栏、表单和工具按钮上的滚动不会缩放画布。

## 业务详情标签

右侧有「属性」「业务详情」「Agent」标签。「业务详情」只在当前图形支持业务详情时出现；远程活动还必须已加载对应的详情。切换到没有详情的图形时自动返回属性。参见 [业务图形详情](activity-details.md)。

## 侧栏尺寸

左右侧栏的内侧边缘可以调整宽度，底边可以调整高度，内侧底角可以同时调整宽高。

| 侧栏              | 最小宽度 | 最大宽度 | 高度范围           |
| ----------------- | -------- | -------- | ------------------ |
| 图形库            | 180px    | 420px    | 280px 至工作区高度 |
| 属性／详情／Agent | 260px    | 600px    | 280px 至工作区高度 |

窄窗口中最大宽度会进一步收紧，为画布保留操作空间。侧栏内容在内部滚动，尺寸在本机保存，不进入业务文档，也不产生远程业务写入。拖拽完成后画布重新适应可用空间。

手柄支持键盘：方向键每次 10px，按住 Shift 每次 30px；Home 调整到最小值，End 调整到最大值。
