# Diagramly

基于 Vue 3、TypeScript、maxGraph 的独立业务绘图编辑器，配套 Fastify + PostgreSQL 后端。图形采用 JSON 文档保存，不依赖 Coopwire 服务、宿主弹窗或历史图形包。

## 启动

推荐 Node 24。运行 npm ci；配置 DATABASE_URL、DIAGRAMLY_CREDENTIALS（首次管理员，用户名:密码），分别运行 npm run server 和 npm run dev。开发时 /api 代理至 127.0.0.1:3000。

仅绘图时可以直接运行 npm run dev，使用 IndexedDB 本机草稿。要使用文档库、业务数据、附件、讨论和账号管理，需要启动后端并登录。

## 工作空间

- 画布支持组合活动、泳池泳道、方向切换、连线、网格背景、缩放滚动、复制删除、撤销重做及沉浸绘图。
- 文档库支持新建、打开、搜索、复制、回收站、恢复，编辑后自动保存 JSON；本机保留草稿副本。
- 历史快照与文档写入在同一数据库事务中完成；可以比较、命名版本并恢复为新版本。
- 打开文档发现不同的本机草稿时，可以将草稿另存为副本，或明确使用服务端内容；不自动覆盖远程冲突。
- 工作空间管理维护角色、应用、设备、终端、接口、数据对象、表与字段、单证、需求、待办和附件。
- 附件支持上传、下载、关联和删除；每个文件最大6MB，保存在数据库，仍被文档引用时不可删除。
- 讨论通过稳定对象 ID 关联图形；支持回复、解决和重新打开，删除图形不删除讨论。
- 流程体检检查不可达活动、开始结束节点与判断分支等问题，允许业务回退环路，结果不代表业务逻辑已完整验证。
- 账号有管理员、编辑者、只读用户三种工作空间级权限，密码使用随机盐和 scrypt 存储，支持修改本人密码。当前不提供文档级分享权限或独立用户端。
- JSON 为标准数据格式；XML 保留为可选文件导入导出格式，PNG 支持透明背景。Agent 实验入口保留，本阶段不扩展 Agent。

## 部署与验证

当前 IP 入口为 http://47.116.6.132/diagramly/，使用 HTTP，账号信息没有传输加密；证书按用户要求暂不处理。

服务器通过 systemd、Nginx 和 PostgreSQL 运行，配置与凭证不进仓库。参见 [独立服务说明](docs/standalone-server.md)。Docker Compose 配置供新环境使用。

npm run build 执行类型检查和生产构建；npm test 执行单测；npm run test:e2e 执行真实浏览器回归；npm run format 和 npm run format:check 负责格式化与检查。
